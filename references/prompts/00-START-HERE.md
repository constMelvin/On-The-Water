# How to use these prompts

1. Copy the whole `reference/` folder into the root of your repo (so you have `reference/otw/...`). Commit it or keep it untracked; either is fine.
2. Run the phases in order, one Claude Code session per phase. Review before starting the next.
   - phase-1-foundation.md
   - phase-2-shell.md
   - phase-3-dashboard.md
   - phase-4-plan-skeleton.md
3. Open `reference/otw/otw-app.html` in a browser to compare as you go. Use the Demo button (bottom-right) to see gala day, done, member view and every state.
